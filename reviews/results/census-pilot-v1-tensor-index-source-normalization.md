# Frozen-v1 tensor-index source normalization

The companion JSON records **all56 exact frozen tensor-index IDs**, plus a
separate proposed `HandleDynamicSlice/nested-after-scaled-probe` child derived
exclusively from frozen source. There are 45 ordered source stages,
41 shared contracts and 252 exact excerpts with SHA256 hashes.
Every case records preceding CONTINUATION requirements, current captures/local
assignments, ordered construction/mutation, and terminal/API/error outcomes.

All six bodies and direct local helper paths were inspected. One Broadcast
sinking row is explicitly a caller alias; its helper may change multiple users.
The proposed scaled child retains operand stripping across the failed Iota probe
and records the actual nested writes that drop the original Multiply.

The actionable reconciliations are actual typed Gather GE/Select construction;
Constant-index DS terminal skips and its original NonConstant-opcode guard;
unit-descriptor extent>1 tests; DS/DUS index-vector copies versus live writes;
DUS operand2 access before scalar/full-update fallback; ordered Concat/Pad skip
and postallocation failures; and partial nested mutations before MarkAsChanged.
The JSON distinguishes exact source predicates from properties their names imply.

All56 local case entries and the proposed child are explicitly normalized under
declared boundaries, with no silently omitted local entries. Missing constructor,
analysis and recovery implementations, virtual layout overrides, legacy-encoding
verifier applicability and global caller reachability remain listed separately.
These boundaries do not imply that Lean proofs are prerequisites for a source
census. No native run, canonical edit, source/proof acceptance or N/F freeze was
performed. Previous review/normalization artifacts are preserved.
