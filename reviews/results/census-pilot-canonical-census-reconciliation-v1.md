## Unit and scope choice

One unit is the concrete eligibility/action program at an ordered source stage,
with its finite guarded variants, loop program and capture bindings. Dtypes,
ranks, orientations and loop iterations parameterize that program. Different
constructed graphs remain explicit child variants. Skip/error/cost-veto and
partial-mutation outcomes belong to the same program; they are not separate
successful rewrites. Caller aliases contribute substitutions and continuation
state, while shared APIs contribute frames and outcome behavior.

This choice preserves both direct nested DynamicSlice and the failed-scaled-probe
child in one stage unit with different input/capture variants. It preserves all
six Dot mirror variants and their different construction/guard paths. It also
retains singleton/cropped/reduced and pointwise convolution branches. This is an
explicit source-program grouping; another policy can choose different granularity
only by versioning the mapping and retaining these source distinctions.

The scope is the base visitor under actual source caller contexts and declared
backend interfaces. Whole-pass reachability is a separate profile. Incorrect,
unsupported or ill-defined attempted transformations remain census obligations.
No mathematical correctness theorem is required to enumerate an attempted action.

## Effects and caller composition

The tables retain Dot mirror and Slice-through-Dot allocations before veto,
Concatenate rejected-attempt allocations and terminal behavior, reduction-Dot
optional-error swallowing, continuing Bitcast replacements, continuing convolution
scalar rewires, and promotion's false return after updating the current pointer.
Later stages consume that current state. A compatibility failure or returned
false/null is not automatically an unchanged graph. AddInstruction counts are
site counts; loops and callbacks can execute a site repeatedly.

The 152 selected effect calls extend the old49 with explicit setters/clearers,
layout callbacks, sorts and metadata/module/state operations. All 436 assignment
expressions are retained, including ordinary local captures and arithmetic.
ReshapeLayoutDimensions' pointer writes1759/1800 modify the copied local Shape;
mutable_operands in the slice handlers returns a vector copy. Driver computation
state and fixed-point flags are support, not tensor transformations. Mutable
getters are projections, not standalone writes; their uses feed separately
classified writes and API calls. Constructor and library semantics remain pinned
interfaces rather than invented proofs of purity or algebra.

Attachments based on action spans are conditional incidence links. Their source
contexts and variant guards remain mandatory. They do not assert that every
profile of a unit reaches every attached event. Static reachable-endpoint lists
alone are not caller feasibility evidence.
