# Independent review of Slice of Pad

**Accepted mathematical observations** for `HandleSlice/inside-pad`, `HandleSlice/undo-pad` and `HandleSlice/padding-only`. The scope is legal static shapes under exact integer arithmetic and extensional equality for arbitrary pure homogeneous element values. This review establishes no native execution, source correspondence, dynamic-size or type-conversion semantics, layout or sharding validity, graph effects, or successful replacement status.

## Source and statement checks

I checked [the pinned HandleSlice implementation](../../../sources/xla/xla/hlo/transforms/simplifiers/algebraic_simplifier.cc#L7655) at XLA `e58e523b11f1fde802a493a776d158007486e1bf`. The compatible identity Slice returns first. The per-axis `limit <= low || start >= size - high` test then breaks and the fill broadcast returns before undo. Undo requires `start == low` and `stride - 1 == interior` on every axis and a successful compatible replacement. The shifted Slice follows if `start >= low`, `limit <= size - high`, `interior == 0` and `stride == 1` on every axis and no prior action returned. The three Lean hypotheses state sufficient mathematical domains independently. Earlier-branch exclusion and replacement success are unnecessary for those equalities. In `Undo` the typed Slice output is the original input shape `s`, the logical projection of the successful compatibility requirement. The source has additional `SameShape`, control-predecessor and replacement checks at [lines 623–634 and 858–879](../../../sources/xla/xla/hlo/transforms/simplifiers/algebraic_simplifier.cc#L623).

I checked [Pad and Slice shape inference](../../../sources/xla/xla/service/shape_inference.cc#L742) (Pad 742–800, Slice 3424–3495), the [Pad evaluator](../../../sources/xla/xla/hlo/evaluator/hlo_evaluator.cc#L6968), and the [slice coordinate lemma](../../../TensorRewrite/Pilot/IndexMapLemmas.lean#L21). Pad extents use `max(0, size-1)` and original samples lie at `low + index * (interior+1)`. `IsWellFormed` requires `0 ≤ start ≤ limit ≤ paddedExtent`, positive stride, and the stated count. `sliceIndex_val` justifies the projection after converting the nonnegative integer coordinate to a bounded natural. `Inside` derives legality of both shifted bounds and preserves the count by translating by the same signed low. The selected point is then proved equal to the replacement Slice point. `Undo` reconstructs precisely the original index from the output index and the guarded lattice spacing. `PaddingOnly` uses a witness axis to infer the Pad selection is absent. For nonempty input the actual right edge is the historical occupied-span expression. For empty input the actual right edge is `low`, which implies the weaker historical right-outside inequality `low - interior ≤ start`. The proof retains the actual source guard and makes this implication in the proof, including the zero case. Empty output has no indices on a zero axis. `Inside` still constructs legal attributes there. Rank zero has no outside-axis witness.

The artifact history already contains analogous mathematical results. `slice/rule04` uses `InteriorSlice.slice_occupied` for nonnegative Pad edges and `slice/rule06` uses `PadSlice.slice_after_pad` for nonnegative Pad edges and unit-stride/no-interior geometry. The new `Undo` and `Inside` are signed-source-guard formulations drawing on the existing signed Pad lattice. `slice/rule05` is the direct historical `slice_outside` reuse with a new source `size - high` guard adapter. Comparing [the historical helper and its supporting lemmas](../../tensorright-v1/SignedPad.lean#L99) against `OutsideReuse.lean` found the same statements and proof steps apart from the local `ring` replacement by `Int.mul_add`, `Int.sub_mul`, `Int.mul_one`, `Int.one_mul`, and `omega` for the same integer equality. The extracted SignedPad and lattice modules retain the needed definitions and use proof-only simp-name ports. None of this changes the historical artifact verdicts.
