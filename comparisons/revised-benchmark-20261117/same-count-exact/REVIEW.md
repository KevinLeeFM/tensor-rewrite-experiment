These are two characterizations of one partition, not two completed rewrites or evidence that the retained source records are complete.

- `pointwise_iff`: for any static reduction plan with equal input and output element counts, a binary operation and the actual initializer, reduction and reshape of a particular logical tensor are equal exactly when the initialized operation fixes each observed reshaped value. The quantification includes every plan, every value type in the model's universe `Type`, every valid input, and every bounded output coordinate.
- `uniform_iff`: for the same fixed plan, operation and initializer, correctness for every logical input is equivalent to zero output cardinality or a left identity on the entire value type. The zero-cardinality disjunct is material. Equal counts at zero do not force reduced axes to have unit extent.
- `reduce_at` derives positive cardinality from any observation. Factoring element counts then forces each fiber to have size one. The earlier unit-index/reshape-index equality relates the actual enumerated input to reshape's dim0-major coordinate, and folding a singleton gives `op init x`. The uniform forward direction chooses a constant tensor at an actual output coordinate, so it has no circular assumption of global identity or tensor equality. The backward direction directly reuses `reduceTensor_sameCount` and `tensor_eq_of_empty`. The existing theorem and previously reviewed wrapper gave sufficiency under left identity. They did not establish either necessity or the exact fixed-input criterion.
