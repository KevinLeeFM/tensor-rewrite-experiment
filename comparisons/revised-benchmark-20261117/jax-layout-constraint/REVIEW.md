# Independent review: JAX `with_layout_constraint` model

**Verdict:** The theorem is correct for the frozen abstract finite dense-layout model and accurately separates the XLA simplifier's forward-versus-copy behavior. The official JAX producer and lowering support the stated one-operand `LayoutConstraint` path. This is not proof of native execution, a universal JAX/XLA backend contract, or physical copy costs. The generic Lean layouts are arbitrary address bijections; correspondence to the producer is limited to the disclosed static dense layouts and matching logical shapes/types.

## Producer, lowering, and XLA branch

I fetched the official JAX [`pjit.py` at `jax-v0.8.1`](https://github.com/jax-ml/jax/blob/jax-v0.8.1/jax/_src/pjit.py#L2979-L3015) directly using the connected GitHub file reader. Its returned blob is `62b00483fb1eade92b0d66c463619367427777a1`. The registered lowering lines are [in `mlir.py`](https://github.com/jax-ml/jax/blob/jax-v0.8.1/jax/_src/interpreters/mlir.py#L2979-L3001), blob `a5bb3d35cdfe2f336a699438e2498425ca0626b2`; the [`Layout` definition](https://github.com/jax-ml/jax/blob/jax-v0.8.1/jax/_src/layout.py#L19-L74) was also fetched, blob `1634b02838b70d20c9b996b8ef2bec1ba31cba8e`. In `pjit.py`, `layout_constraint_p` has abstract evaluation `lambda x, **_: x`. Eager evaluation returns x when `x.format.layout == layout`; otherwise it JITs `_identity_fn` with `Format(layout, x.sharding)`. The registered lowering calls `wrap_with_layout_op` with the input/output avals. `mlir.py` emits a one-operand custom call named `LayoutConstraint`; it sets the output layout from `layout.major_to_minor[::-1]` and comments that XLA ignores the placeholder input layout.

JAX `Layout` also supports tiling and sub-byte element-size metadata. Those are excluded by the freeze; this review does not generalize the theorem to tiled or packed sub-byte addressing. Dynamic shape results, sharding effects, aliasing, and runtime execution are likewise outside the model. The packet's layout is a bijection from logical coordinates to a finite physical address set, sufficient for a static dense permutation layout. `CopySpec.copy` models a logical copy by reading the source address for the destination's decoded coordinate.

In the pinned XLA source, `SameShape` is `ShapeUtil::Equal` in layout-sensitive mode and `ShapeUtil::Compatible` otherwise. `HandleCustomCall` processes `LayoutConstraint` only when layout-sensitive: equal shape/layout forwards the operand; otherwise it constructs a `Copy` with the result shape. The frozen XLA source hash matched and the local test `LayoutConstraintToNoop` / `LayoutConstraintToCopy` exercises precisely those alternatives (the tests use unverified modules). The official XLA [`layout_assignment.cc` at `e58e523b`](https://github.com/openxla/xla/blob/e58e523b/xla/service/layout_assignment.cc#L3059-L3069), blob `9e73032426ead03381f896f38e33c2646c646060`, additionally constrains the custom-call output and sets the LayoutConstraint operand layout to the result layout. That is layout-assignment evidence, not a run of the compiler pipeline; ordering and backend physical realization are not established here.

## Lean statement and controls

`LayoutConstraint.Goal` quantifies over any finite logical index type and payload type, source/destination bijective layouts and array storage. It assumes that the `same=true` branch entails identical logical-coordinate addresses; for `same=false`, it equates the original value with a copy that reads the source at the destination's decoded logical coordinate. This matches `SameShape`'s intended same-layout branch, but the implication is stated as a model condition; the packet does not prove `ShapeUtil::Equal` implementation equals Lean address equality for every XLA layout representation.

The theorem's proof is direct: congruence on the identity addresses in the same-layout branch, and source/destination encode-decode for the copy branch. The controls check a concrete differing rank-2 layout: original logical index 0 reads source value 0; correct copy also reads 0; incorrect raw forwarding under destination's reversed address reads 1. Equal-layout and empty-index controls also compile. The rank-2 case is only a control; the theorem is generic. The change to explicitly bind payload `α` addresses the retained first-draft elaboration error; `failed-binder.log` is historical failed evidence, not part of the successful proof closure.
