**What was checked.** The definitional signatures in RemapProof are ordinal_correct : OrdinalGoal and reverse_remap : Target. The first recovers the ordinal of every retained axis from its position minus the count of inserted predecessors. The second uses the actual ordered list of output dimensions, filters *all* unit axes, and maps the survivors using this ordinal. It proves range unconditionally and uniqueness for distinct inputs. The proof connects input selection by membership in the emitted naturals to the old remapped Boolean mask via injectivity of the decoded axes. The original selection is membership in the given output-axis list. On both sides orderedReshape identifies the projection with Reshape.reshapeTensor (output linearization and input delinearization). The inherited reverse_reshape then gives tensor equality for every value type. No axis/result legality or mask equality is hidden in a premise. Rank is arbitrary and both count zero and rank zero are admitted.

**What the static source selects.** The XLA snapshot at e58e523b, algebraic_simplifier.cc:7200–7232 and 7287–7320, first forwards all-trivial reverses. For the layout-insensitive reshape arm the returned deletion list must be empty. The source traverses dimensions in caller order, skips size one, and uses binary search on the sorted inserted list. The semantic reading of that search as a count is assumed. shape_inference.cc:3770–3785 requires unique in-range axes. hlo_instruction.cc:5587–5594 delegates to shape_util.cc:1624–1706. The descriptor walks gaps in increasing order and rejects any modified dimension greater than one. With positive static product, accepted gaps have extent one. A retained 1-by-1 block has equal extents by the product contract of util.h:784–798. No deletion therefore retains every input position in order. As a nontrivial reachable descriptor under this contract, [5] to [1,5] retains the two extent-5 positions, inserts position 0 and maps reverse dimension 1 to 0. The same arrays supplied to CommonFactors are illustrated in shape_inference.cc:4142–4160. This is reasoning from the helper contract and source, without running XLA.

For equal zero-product vectors, every axis boundary is retained. For unequal zero-product vectors CommonFactors returns just the endpoints. These cannot form a 1-by-1 pair (two rank-one zero-product vectors would be identical). Input rank is positive, hence at least one deletion must occur if the helper succeeds. Consequently [0] to [0,0] with no deletion cannot reach the static arm. The compiled control shows this malformed descriptor admits an out-of-range emitted integer under the weaker omitted-extent-at-most-one assumption even though element counts match. Other controls discriminate a legal but wrong unshifted axis on nonconstant data (2 versus 10), list order, and scalar/empty cases. No source counterexample follows.
