# Packed literals and the physical bitcast rewrite

The result is a model counterexample for one static, little-endian evaluator profile. Both directions are tested under the same source record. For the join, two U4 input elements with values [1,1] are stored in two literal bytes. BitcastConvert produces the U8 value 17; ordinary bitcast copies the first byte and returns 1. This witness is independent of nibble lane numbering. For the split, BitcastConvert on any U8 succeeds, whereas the modeled evaluator bitcast fails its size check. In particular 17 unpacks to [1,1]. Zero nibbles are a joining control. Removing explicit E(4) rejects this axis in the source guard.
