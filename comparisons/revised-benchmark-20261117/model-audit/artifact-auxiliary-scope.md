## Scope and evidence

**PadTwice.** Both pads and the replacement share the same fill. Each replacement edge/interior is the sum of its inner and outer counterparts, outer interior is zero, and both inner edges are nonnegative. The outer edges may crop. The AST uses generic pad, whose defined accesses test bounds and the inner stride (src/TensorRight/Internal/Core/Tensor/Typed.hs:690–740). The required index test subtracts outer then inner low versus their sum, with the same inner-spacing divisibility and input bounds. Existing PadWindow.axis_compose and contribution_fusion concern a padded window. SignedPad.unit_interior and pad_shift concern different reductions. None of these named receipts alone certifies the complete nested pad terminal. A separately owned new proof packet must report its own verdict and timing.

**PadLowCombine.** The source uses the dedicated padLow decoder at Typed.hs:744–786, two nonnegative low pads and a common fill. For an output coordinate below the outer low, or whose translated coordinate is below the inner low, the result is fill. Otherwise it reads the input at the coordinate less their sum. These conditions become a single threshold on the summed low. This is the restricted mathematical calculation from PadTwice with zero high/interior; verifying the separate decoder justifies a declaration link without another independent discovery.

**DynamicSlice.** The comment immediately before the RHS says the rule needs a precondition on “a”. The declaration registers no such condition or SI relation. Its finite TensorInt symbolic constant comes from TensorInt.hs:86,251; Typed.hs:556–567 and 594–605 implement the constant and iota. Typed.hs:899–925 checks nonnegative starts/sizes, in-bounds end, then reads start plus local index. On input [0,1], start 0 and length 1, the output is [0]. Choosing the independent literal 1 yields the one-element RHS [1]. The equal shapes and an admitted index rule out a shape-only failure. Historical Iota.lean and Dynamic.lean involve different replacements. The frozen statement, theorem, controls, compiler output and source hashes are in ../artifact-dyslice-aux. This models a finite singleton-axis witness; no artifact SMT run or native result is attributed.

**Generalized convolution.** README.md:26,205 and Makefile:11–12 document separate verification via make generalize. Positive input/kernel spatial extents, zero padding fill, eligible nonnegative edge widths and unit spatial stride support translating the DSL parameters to the existing semiring law. Typed.conv implements dilation via inserted padding of dilation minus one; legal interior padding excludes zero effective dilation (Typed.hs:699–715,1090–1105). On each spatial axis with base dilation d and inner interior p, the new base dilation is d*(1+p), and the external edges become low+d*plow and high+d*phigh. Kernel dilation, kernel values and summation axes persist. The all-output equality is comparisons/tensorright-v1/PadConvolution.lean:104 convolve_fusion. Its pad and window constructors use TensorRewrite/Theory/PadWindow.lean's fusedLow and fusedAxis; PadWindowLemmas.lean:75 fused_high_nonempty supplies the high-edge identity for this positive-input DSL domain. The paper_edges receipt alone only handles unit base dilation. pad-convolution-check.log records propext, Classical.choice, Quot.sound for convolve_fusion; reports/mathematical-ledger-audit.log records propext and Quot.sound for fused_high_nonempty. This extends the explicit artifact mapping with inherited mathematics. Exceptional TensorNum arithmetic and automatic DSL/Lean correspondence are outside the semiring claim. No fresh verifier execution or new proof-search timing accompanies this link.
