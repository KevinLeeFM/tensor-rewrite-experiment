# Ordered single-slice blocks: review checkpoint

Result: a generic ordered list of equally sized, individually legal source intervals can be transported into one concatenation frame. The checked lemmas derive its total extent, full output shape, selection of a specified list block, its actual source-tensor coordinate, and quotient/remainder arithmetic for equal positive block extents. This is reusable support only: **the space-depth rewrite is neither stated nor proved**. Stop for independent review.

`OrderedSlices.lean` defines `Interval extent length` with `start + length ≤ extent`; `blocks` maps a caller-supplied list of intervals in exactly that order to the reviewed `sliceBlock` construction. The list need not be contiguous or sorted: this is deliberately more generic than the proposed rewrite. `blocks_total` derives `intervals.length * source.shape length axis`; `output_shape_axis` gives each result extent. `select_block` proves selection for an explicit decomposition `leading ++ chosen :: trailing` and a bounded coordinate within that block; `select_source` unfolds to the actual source tensor read; `sourceIndex_split_value` states the source split coordinate is `chosen.start +` the transported local coordinate. `sourceIndex_chunk_value` specializes this when the caller establishes `chosen.start = chunk * length`. `segment_quotient_remainder` relates a nonempty block's equal-size segment to its quotient/remainder. These premises assert interval legality and structural start, not the target tensor equality.

The bridge is not yet an automatic source-case list: it does not construct `[0*c,1*c,…]`, prove its starts are ordered/contiguous, or combine the prefix selection and quotient facts into the final reshape/transpose theorem. No proof relates the latter operator maps. The original draft's outer-rank `m ≥ n` remains a model restriction, not an established source invariant. These omissions must stay visible in any later exact statement and review.

## Controls and generality

Arbitrary finite rank (an actual axis rules out rank zero), arbitrary tensor value type in Lean `Type`, extents and legal interval lists are supported. `Fin` coordinates make zero destination extent uninhabited; no artificial default value is read. Empty lists have total extent zero and no result coordinate. Zero-width slices and separate zero axes have empty output-index domains. These statements do not infer global tensor nonemptiness.

`OrderedSlicesTests.lean` checks segment boundaries using input value `10*i+j`: the last element of block one yields 2 and the first of block two yields 20. A well-typed wrong-concat-axis control gives 10 versus the correct 20 at the corresponding flat position 3. Concrete controls cover empty list, zero-width slices, another zero extent and a known total of 6. These are finite examples rather than source-level XLA execution or a general wrong-rewrite refutation.
